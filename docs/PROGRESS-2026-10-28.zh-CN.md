## 已实现并通过聚焦回归

- 回放来源绑定实际协议、端点、凭据和请求头，以私有随机密钥 HMAC 生成不可反推的身份。会话恢复可复用同来源状态；更换来源、历史无身份时不外发旧签名/加密状态。压缩提示同样去除这些数据。这是 Go 端的来源隔离加固，HMAC 字段不是上游原样格式。
- 委派子代理耐久目录、冷恢复、权限上限、独立预设、深度上下文、按 activation root 的并发池及清理/通知边界。旧数据缺 descriptor 时只提供诊断，不伪造可恢复能力。
- 工作流 activation-scoped `structured_output`：参数按 schema 验证，错误可在同回合重试；原生工具或外层 PTC 成功之后才提交；普通 JSON 文本不作为成功提交。覆盖 standard、minimal、PTC、持久 PTC 四条集成路径。
- UTF-8 终端编辑、光标/词移动、历史隔离、补全菜单、粘贴、窗口变化和后台输出重绘。CLI 输入 broker 逐次携带历史/补全策略，审批与问答不进入聊天历史。
- `/` 命令、`@` 文件及会话候选。文件发现不读取内容；有界索引、目录实时查询、失效后后台刷新、目录 symlink 拒绝与官方排序有回归。
- 会话引用 URI、冻结文本快照、来源过滤、字节保留、完整 spill 和取消。实际 admission 时通过一个 `user/input` 事件原子提交 direct+contexts；Inbox、分叉、恢复、压缩、轨迹及收据识别该分组。
- 目标的官方轮数/CAS/authority、进程内 arm/reservation、实际 admission 计数、首请求版本栅栏、暂停/完成/阻塞、重启/分叉不自动执行。后台 driver 与 headless 完成边界已接。
- 日程同会话 recurring 合批、Host 管理/投递 FIFO、共享收据、部分提交失败、失败不自动重试、真实旧格式兼容、忙时持久 Inbox、未完成 turn 恢复、时区别名与保留设置。
- 后台任务的等待设置、quiet 投递、连续唤醒预算、人类输入 admission 后重置、按所属树静止检查，以及 producer 输出限额的模型投影。canonical value 保持完整，错误仍保留原始 error 链。
- MCP 初始失败非致命、stdio 代次恢复、工具变更同步、配置重载、指令归属、durable 图片和输出 schema。新版 SDK 的发现/legacy fallback、一次性 stdio probe、meta、订阅、SSE 恢复、分页、缓存、显式 input_required 状态续接已有 golden wire 回归。

## 本次更正的旧清单假设

1. 官方工作流通过临时 `structured_output` 工具提交，不是供应商 `response_format`。不能按错误假设添加原生 JSON Schema API 开关。
2. 官方 goal 核心限制自主轮数，默认 256，配合 ID/revision CAS；不是 token budget。原 Go token-budget 规则已被替换，旧历史只保留只读 objective 诊断。
3. 官方 token-meter 本身包含估算，不要求第三方精确 tokenizer。仍需移植的实际行为包括 usage anchor、视觉/文件价格、delta、pruner 与 compaction 策略。
4. 官方默认 MCP 音频和嵌入资源采用诊断；资源订阅、prompt templates、task-required 执行不是这份桥接器已有的产品能力。不能把它们列为必做新增功能。
5. MCP 新版不是在 `initialize` 中返回新版版本号。必须核对 SDK 2.2.0 的 `server/discover`、协议 metadata 与 probe/serving 分离。
6. 官方侧栏交互终端与模型私有 terminal 服务分离。不能以共享 minimal 模型 PTY 的额外入口冒充侧栏移植。

## 可重复的验证入口

本机 Go 缓存放在 `/private/tmp/dsgo-go-cache` 和 `/private/tmp/dsgo-go-mod`。本地监听、真实 PTY、系统沙箱测试需要正常宿主权限。

```sh
GOCACHE=/private/tmp/dsgo-go-cache GOMODCACHE=/private/tmp/dsgo-go-mod \
  go test -race ./... -timeout=60s
GOCACHE=/private/tmp/dsgo-go-cache GOMODCACHE=/private/tmp/dsgo-go-mod \
  go vet ./...
python3 scripts/verify-upstream.py
git diff --check
```
